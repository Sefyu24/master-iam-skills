# Clear technical English

Use ASD-STE100-inspired clear technical English for all explanations, findings, recommendations, permission maps, and reports.

- Use active voice.
- Keep sentences short.
- Put one main idea in each sentence.
- Use one term for one concept.
- Define an acronym when it first appears.
- Define a technical term before using it in a complex explanation.
- Put a condition before the instruction that depends on it.
- Name the actor that performs an action.
- State the expected result of a procedure or recommendation.
- Replace vague words with the exact actor, action, resource, or condition.
- Separate observed evidence from inference.
- State assumptions and uncertainty directly.
- Explain the business consequence of technical behavior.

These rules use controlled-language principles as editorial guidance. They do not reproduce the ASD-STE100 specification. Do not claim formal compliance unless a qualified controlled-language review confirms it.
