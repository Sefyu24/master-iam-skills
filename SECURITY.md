# Security policy

## Authorized use

Use the review skill only on systems, repositories, and environments that you are authorized to inspect.

Do not use it to access another person's data, obtain credentials, or bypass controls on a live service.

## Reporting a repository vulnerability

Use GitHub private vulnerability reporting when it is available. Otherwise, contact the maintainer through a private channel listed on the maintainer's GitHub profile.

Do not place credentials, private source code, personal data, or usable exploit details in a public issue.

You can report documentation errors and false positives in a normal issue after you remove sensitive information.
